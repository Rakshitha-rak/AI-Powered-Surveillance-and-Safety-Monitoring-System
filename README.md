# AI-Powered Surveillance and Safety Monitoring System

An AI-powered surveillance and safety monitoring system designed to support real-time monitoring and intelligent safety analysis. The project combines a modern web interface with computer vision concepts to provide an efficient and user-friendly monitoring experience.

## Features

* Real-time safety monitoring
* AI-powered surveillance
* Object detection and monitoring
* Safety-focused user interface
* Interactive monitoring dashboard
* Login interface
* Responsive web interface

## Technologies Used

* React.js
* Vite
* JavaScript
* HTML
* CSS
* Python
* YOLO
* OpenCV

## How to Run

### Install Dependencies

```bash
npm install
```

### Start the Application

```bash
npm run dev
```

The application will be available at the local URL provided by Vite.

## Objective

The objective of this project is to develop an intelligent surveillance and safety monitoring solution that can assist in detecting objects, monitoring environments, and improving safety through AI and computer vision technologies.
